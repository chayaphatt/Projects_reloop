# Reloop - E-Commerce Web Application

เว็บไซต์อีคอมเมิร์ซเต็มรูปแบบ เป็น Final Project โดยเป็นการทำงานร่วมกันในทีม 3 คน เพื่อนำความรู้ด้านการพัฒนาเว็บไซต์มาประยุกต์ใช้ในการสร้างระบบร้านค้าออนไลน์ที่มีฟังก์ชันครอบคลุมตั้งแต่ส่วนติดต่อผู้ใช้ (Front-end) ไปจนถึงระบบจัดการหลังบ้าน (Back-end)

## About This Project

โปรเจกต์นี้เน้นการออกแบบประสบการณ์ผู้ใช้ (UX/UI) ที่ลื่นไหลและมีระบบการทำงานที่สมบูรณ์ โดยมีฟีเจอร์หลักดังนี้:

* **ระบบจัดการผู้ใช้งาน:** รองรับการสมัครสมาชิก เข้าสู่ระบบ และมีหน้าโปรไฟล์ส่วนตัวสำหรับให้ผู้ใช้จัดการข้อมูลและตรวจสอบประวัติการสั่งซื้อ
* **ระบบแคตตาล็อกและตะกร้าสินค้า:** จัดแบ่งหมวดหมู่สินค้าอย่างเป็นระบบ ผู้ใช้สามารถเพิ่มสินค้าลงตะกร้า ปรับจำนวน และระบบจะคำนวณราคารวมให้อัตโนมัติ
* **ระบบการชำระเงินและการจัดส่ง:** มีหน้าต่างสำหรับสรุปยอดรายการสินค้าและแบบฟอร์มสำหรับกรอกข้อมูลที่อยู่จัดส่งเพื่อยืนยันคำสั่งซื้อ
* **ระบบสนับสนุนลูกค้า:** ติดตั้งระบบแชทส่วนหน้าเว็บแบบเรียลไทม์เพื่ออำนวยความสะดวกในการติดต่อสอบถามข้อมูลกับทางร้าน
* **ระบบการจัดการของผู้ดูแล (Admin):** มีแดชบอร์ดเฉพาะสำหรับแอดมินเพื่อตรวจสอบรายการสั่งซื้อทั้งหมด และจัดการอัปเดตสถานะการจัดส่งสินค้า

### Tech Stack

* **HTML5:** สร้างโครงสร้างเนื้อหาและองค์ประกอบแบบฟอร์มต่างๆ ภายในหน้าเว็บ
* **CSS3:** ตกแต่งสีสัน จัดเลย์เอาต์ และปรับหน้าตาเว็บไซต์ (UI) ให้มีความสวยงามน่าใช้งาน
* **JavaScript (Vanilla JS):** ควบคุมการทำงานแบบไดนามิก เช่น การคำนวณราคาสินค้าในตะกร้า การโต้ตอบของระบบแชท และฟังก์ชันการสั่งซื้อ
* **Node.js:** จัดการระบบฝั่งเซิร์ฟเวอร์ (Back-end) เพื่อรองรับการทำงานของระบบจัดการข้อมูล
* **JSON:** ใช้เป็นรูปแบบการจัดเก็บข้อมูลจำลองสำหรับสินค้าและข้อมูลที่จำเป็นในระบบ
* **GitHub Pages:** ใช้สำหรับเผยแพร่และแสดงผลหน้าเว็บไซต์ฝั่ง Front-end ออนไลน์
